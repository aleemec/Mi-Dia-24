# Mi Día 24h

Planificador diario de 24 horas. Funciona 100 % en el navegador: no tiene servidor, cuentas ni claves, y los datos se guardan solo en el `localStorage` de tu equipo.

## Uso
```
npm install
npm run dev        # desarrollo (solo accesible desde tu equipo)
npm run build      # producción -> dist/
npm run preview    # prueba la versión de producción con cabeceras de seguridad
npm run audit:deps # revisa vulnerabilidades en dependencias
```
`npm run dev:lan` expone el servidor de desarrollo a tu red local; úsalo solo en redes de confianza.
